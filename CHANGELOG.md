# Changelog
## 1.2 (2026-10-07)
- Renamed to **things for EUI** cause I was breaking Ellesmere's rules 🙈 Read the FAQ next time dumbdumb.. Anywhooo, the folder is now `thingsForEUI`. Just update, your settings move over on your first login. After that you can delete the `EllesmereUIThings` folder if you want.
- Options have their own "things for EUI" section in the EllesmereUI sidebar
- `/tui` opens the options, `/tui install` opens the installer
- New: Gruffs Preset / Nala Style under Move That Stuff. Nala Style stacks action bars 1-2-3 (1 at the bottom), hides 4-5-6 and runs Move That Stuff. Gruffs Preset puts it all back.
- Installer: sets up EllesmereUI sync groups for the pack profiles (everything except Unit Frames, Cooldown Manager, Resource & Cast Bars and Raid Frames). Sync groups you already have with your own profiles are left alone.
- Installer: new Sync Groups button to set up just the sync groups
- Installer window is bigger
- Fixed the Action Bars tab not seeing that Bar 9 was turned off. "Keybinds Follow the Shown Bar" and "Fill the Shown Bar on Each Spec" now work, and Show This Bar can show Bar 9.
