# things for EUI

EllesmereUI Tweaks, fixes and QoL for healing things, or not.

## Features

**Castbars**
- Spell and target name on main and mini castbars.
- Class colored target names.
- Fixes castbar width and fill lag.

**Cooldown Manager**
- Hide passive cooldowns.
- Racials in the Cooldown Manager.
- Trinket blacklist. Hide trinkets you don't want to see.
- Icon borders.
- Utility overflow and wrap.

**Tracking Bars**
- Totem duration bars.
- Color by buff. Warning text when it's missing.

**Action Bars**
- Choose Bar 6 or Bar 9 as your last bar.
- Preview both. Copy spells between them.
- Keybinds follow the shown bar.

**Raid Frame Builder**
- Custom raid order.

**Move That Stuff**
- Minimap and buffs to the top right, damage meter to the bottom right.
- One click back.

**Profile Fixes**
- Unit frame sizes no longer leak between spec profiles.
- Target of Target updates on profile swap.

**Installer**
- `/tui install`
- Installs the thingsEUI pack: EllesmereUI, Edit Mode, BigWigs, Baganator, Cooldown Manager layouts.
- Asks before overwriting.
- Alts get set up with one click.
